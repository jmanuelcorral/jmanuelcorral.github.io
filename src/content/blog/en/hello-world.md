Hi, I'm Jose. I've been building software for more than ten years, professionally with Java, .NET and JavaScript.

My stack is a broad one. These days I survive projects and technologies such as .NET, .NET Core, Node.js, JavaScript, Vue.js, Docker, Kubernetes, SQL Server, IIS, Azure and Azure DevOps.

I'm writing this blog because I'm getting older 😉, I have an information overflow problem, and I need somewhere to dump everything I learn — in case I have to revisit it a few years from now.

So this is, above all, a public notebook. You'll find a bit of everything here: recipes that worked for me, architecture decisions I'm willing to defend, and the occasional faceplant. Good luck digging around.
